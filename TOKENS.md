## 1. Overview

To guarantee visual consistency across generated interfaces, this repository includes the **FigCraft Design Tokens** catalog stored in `tokens.json`.

Using these standardized tokens, UI components generated by AI assistants or custom scripts adhere strictly to modern design system standards (matching Tailwind CSS palettes and 4px-based spacing scales) rather than arbitrary values.

---

## 2. Token Scales Reference

### A. Standard Color Palettes (Shades 50 to 950)
7 curated color palettes spanning the full luminance spectrum:
- **`slate`**: Neutral cool gray with slight blue undertones (`#F8FAFC` to `#020617`).
- **`zinc`**: Neutral monochrome gray (`#FAFAFA` to `#09090B`).
- **`indigo`**: Primary brand accent (`#EEF2FF` to `#1E1B4B`).
- **`sky`**: Vivid sky blue for active states and informational highlights (`#F0F9FF` to `#082F49`).
- **`emerald`**: Vibrant green for success and positive status confirmations (`#ECFDF5` to `#022C22`).
- **`amber`**: Warm amber yellow for warnings, notices, and pending states (`#FFFBEB` to `#451A03`).
- **`rose`**: Soft pinks and deep reds for destructive actions and error badges (`#FFF1F2` to `#4C0519`).

### B. Spacing and Padding Scale
Based on a clean 4-pixel grid:
- `1`: 4px
- `2`: 8px
- `3`: 12px
- `4`: 16px
- `5`: 20px
- `6`: 24px
- `8`: 32px
- `10`: 40px
- `12`: 48px
- `16`: 64px

### C. Border Radius Scale
- `none`: 0px
- `sm`: 2px
- `default`: 4px
- `md`: 6px
- `lg`: 8px
- `xl`: 12px
- `2xl`: 16px
- `3xl`: 24px
- `full`: 9999px (circular / pill shape)

## 3. Command Line Interface (CLI) Usage

The `tokens.py` module can be executed directly from your terminal to render design foundation elements onto the active FigCraft canvas:

```bash
# 1. Display summary of available design tokens
python tokens.py --list

# 2. Render color swatch card on FigCraft canvas (e.g. indigo, slate, sky, emerald)
python tokens.py --palette indigo

# 3. Render standard button component library (Primary, Secondary, Outline, Danger)
python tokens.py --starter-buttons

# 4. Render standard status badges library (Success, Warning, Danger, Info)
python tokens.py --starter-badges

# 5. Output ready-to-paste theme.extend snippet for tailwind.config.js
python tokens.py --export-tailwind
```

---

## 4. Python API Usage in Custom Scripts

You can also import `tokens.py` directly in custom automation scripts:

```python
from tokens import get_color, get_spacing, get_radius

# Fetch hex colors
primary_color = get_color("indigo-600")   # Returns '#4F46E5'
bg_dark = get_color("slate-900")          # Returns '#0F172A'

# Fetch spacing and border radius
card_padding = get_spacing(4)             # Returns 16
button_radius = get_radius("lg")          # Returns 8
```

## 5. Exporting Theme to Tailwind CSS

To align your web frontend project with your FigCraft canvas components, run:
```bash
python tokens.py --export-tailwind
```

Copy the printed JSON snippet into the `theme.extend` block of your `tailwind.config.js` file.
